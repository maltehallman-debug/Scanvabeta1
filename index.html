How it works

Your spreadsheet is the database.

Scanva is a small Apps Script project that lives in your own Google account. It reads and writes one file, and that file is yours: a Google Sheet or a real .xlsx in your Drive.

01 · Your file

Three tabs, one row per day

  • TräningsdagbokLogged sessions
  • PlaneringsbokUpcoming sessions, same layout
  • TräningssammanfattningWeek / time / km, already computed
02 · Your Google account

Apps Script web app

Scanva's Code.gs and Index.html, deployed under your account and executed as you. There's no Scanva server in between.

03 · You

An app on your home screen

Open the link once and add it to your home screen. From then on it opens like any other app.

Questions

Good to know.

Where is my training data stored?

In your own spreadsheet, in your own Google account. Scanva runs as an Apps Script project under your account and reads and writes that file directly. There's no Scanva server and nothing is copied anywhere else.

Does it work with an Excel file?

Yes. A Google Sheet and a real .xlsx file in your Drive both work, as long as they have the three tabs Träningsdagbok, Planeringsbok and Träningssammanfattning laid out one row per day.

Do I need to know how to code?

No. Quick install creates and deploys the project for you after Google's own sign-in and consent screen. If you'd rather do it yourself, the manual route is copy and paste, with an illustrated walkthrough for every step.

What does Pro add?

Pro fully unlocks the AI tab: a daily tip, a load number, goal times, a 7-day plan and a chat, all powered by your own free Gemini API key. It also wires "Get from Strava" to your own free Strava API app. Everything else works the same on both builds.

Can I put it on my phone's home screen?

Yes. Open the web app link once and add it to your home screen, and it opens full screen like any other app.

Set up Scanva

Control 1 of 8

Open your training-diary file

A Google Sheet or a real .xlsx file both work — it just needs three tabs named exactly Träningsdagbok, Planeringsbok and Träningssammanfattning, laid out one row per day.

Control 2 of 8

Copy its file ID

Open its share link (or just look at the address bar) and copy the long string in the URL between /d/ and /edit — that's its file ID, and it's how the script below will find it, whether it's a Google Sheet or a real .xlsx file.

Control 3 of 8

Create a new Apps Script project

Go to script.google.com and click New project. It isn't attached to your spreadsheet the way "Extensions → Apps Script" would be — that's exactly what lets it reach a real .xlsx file directly, using the ID from the last step.

Control 4 of 8

Paste in Code.gs

Select everything in the placeholder Code.gs file, delete it, and paste in Scanva's version from the next screen — then paste your file ID from the last step into SHEET_ID near the top.

Control 5 of 8

Add an Index.html file

Click the + next to Files, choose HTML, and name the new file exactly Index — Apps Script adds the extension itself.

Control 6 of 8

Paste in Index.html

Open the new Index file, select any placeholder content, delete it, and paste in the whole page's code from the next screen.

Control 7 of 8

Deploy as a web app

Deploy → New deployment → Web app. Execute as yourself, choose who has access, then approve the permissions prompt — it's your own script reading your own sheet.

Control 8 of 8

Open the link

That's it — open the URL it gives you, and add it to your phone's home screen so it feels like a real app.
