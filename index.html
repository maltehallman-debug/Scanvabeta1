Set up Scanva

Control 1 of 8

Open your own spreadsheet

It needs three tabs named exactly Träningsdagbok, Planeringsbok and Träningssammanfattning, laid out one row per day.

Control 2 of 8

Excel file? Convert it first

If your sheet is an .xlsx file rather than a native Google Sheet, open it in Drive and choose File → Save as Google Sheets before continuing — Apps Script can only bind to a real Sheet, not an Excel file.

Control 3 of 8

Extensions → Apps Script

From the spreadsheet's menu bar, open Extensions, then click Apps Script — this opens a code editor already bound to your sheet.

Control 4 of 8

Paste in Code.gs

Select everything in the placeholder Code.gs file, delete it, and paste in Scanva's version from the next screen.

Control 5 of 8

Add an Index.html file

Click the + next to Files, choose HTML, and name the new file exactly Index — Apps Script adds the extension itself.

Control 6 of 8

Paste in Index.html

Open the new Index file, select any placeholder content, delete it, and paste in the whole page's code from the next screen.

Control 7 of 8

Deploy as a web app

Deploy → New deployment → Web app. Execute as yourself, choose who has access, then approve the permissions prompt — it's your own script reading your own sheet.

Control 8 of 8

Open the link

That's it — open the URL it gives you, and add it to your phone's home screen so it feels like a real app.

Control 4 of 13

Add the OAuth2 library

In the editor's left sidebar, click Libraries → the + button, paste in the script ID 1B7FSrk5Zi6L1rSxxTDgDEUsPzlukDsi4KGuTMorsTQHhGBzBkMun4iDF, set the identifier to OAuth2, and add it. This is what talks to Strava on your behalf.

Control 6 of 13

Add an Index.html file

Control 7 of 13

Paste in Index.html

Open the new Index file, select any placeholder content, delete it, and paste in Scanva Pro's page code from the last screen.

Control 8 of 13

Create a Strava API app

At strava.com/settings/api, create a free application. Whatever name you like, and set Authorization Callback Domain to exactly script.google.com — that's the domain your deployed app lives on.

Control 9 of 13

Create a Gemini API key

At aistudio.google.com/apikey, click Create API key. Any Google account works — it doesn't need to be the one your sheet lives in.

Control 10 of 13

Add your keys as Script Properties

Back in the Apps Script editor: Project Settings (gear icon) → Script Properties → add STRAVA_CLIENT_ID, STRAVA_CLIENT_SECRET and GEMINI_API_KEY with the values from the last two screens.

Control 11 of 13

Deploy as a web app

Deploy → New deployment → Web app. Execute as yourself, choose who has access, then approve the permissions prompt — it's your own script reading your own sheet and calling Strava/Gemini with your own keys.

Control 12 of 13

Connect your Strava account

Open the deployed app, tap Get from Strava on any pass, then Connect to Strava — a one-time authorization. Come back and the picker works from then on.

Control 13 of 13

Open the link

That's it — open the URL it gives you, and add it to your phone's home screen so it feels like a real app.
