What Scanva is

Scanva is free. It's an Apps Script project (Code.gs and Index.html) that you copy into your own Google account, where it reads and writes a spreadsheet you own. Nothing is sold on this website and there is no account to create.

You install and run it in your own Google account, so your use of it is also covered by Google's terms. The optional Pro features use your own Gemini API key and your own Strava API app, and are covered by Google's and Strava's terms.
